# Начало работы

## Запуск LeftoverScout

LeftoverScout переносимый. Устанавливать ничего не нужно: запустите `LeftoverScout.exe` из любой
папки. Программа работает от имени обычного пользователя и никогда не запрашивает права администратора.

Слева в окне находится список разделов:

| Раздел | Для чего нужен |
|---|---|
| **Scan** | Сканирует ваш профиль (только чтение) и показывает, что занимает место. См. [Scan](scan.md). |
| **Results** | Показывает, куда уходит место: просмотр папок по размеру и список больших файлов. См. [Results](results.md). |
| **Programs** | Список программ, установленных на этом компьютере; его собирает каждое сканирование. См. [Programs](programs.md). |
| **Cleanup** | Переместит выбранные элементы в Корзину. Запланировано. См. [Cleanup](cleanup.md). |
| **History** | Покажет, что удалили прошлые очистки. Запланировано. См. [History](history.md). |
| **Help** | Эта справка. См. [Как пользоваться справкой](help.md). |
| **About** | Версия, лицензия, ссылка на проект и папка данных. См. [About](about.md). |

Сейчас содержимое есть у **Scan**, **Results**, **Programs**, **Help** и **About**; страницы **Cleanup** и **History**
показывают короткую заметку о том, что они будут делать.

## Только одно окно

LeftoverScout запускается один раз за сеанс пользователя Windows. Если запустить его второй раз,
пока он уже открыт (даже свёрнутый), существующее окно выйдет на передний план, а второй запуск тихо завершится.

## Где хранятся настройки и журналы

LeftoverScout хранит свои файлы в папке `data` **рядом с программой**:

- `data\settings.json`: размер и положение окна и выбранный язык справки.
- `data\logs\leftoverscout-<дата>.log`: диагностический журнал. Хранятся семь самых новых файлов.

Если удалить папку программы, удалится и всё это. В реестр ничего не записывается.
Страница **About** показывает точный путь к папке и содержит кнопку **Open data folder**.

## Жёлтая информационная панель

Если папка программы недоступна для записи (например, она в `Program Files`), LeftoverScout хранит
файлы в `%LOCALAPPDATA%\LeftoverScout` и показывает сообщение:

> Settings are stored in `<path>` because the program folder is not writable.

Это только уведомление. Нажмите **Dismiss**, чтобы скрыть его. Чтобы программа оставалась полностью
переносимой, переместите её в папку, доступную для записи.

## Если файл настроек повреждён

Если `settings.json` невозможно прочитать, LeftoverScout запускается с настройками по умолчанию и пишет
предупреждение в журнал. Файл заменяется новыми настройками.
