# Using this help

## Opening help

- Click **Help** in the navigation to read all topics. The topic list is on the left, the text is on the right.
- Click the **?** button in the top-right corner of any page, or press **F1**, to open the help for the page you are on.
  On the **Help** page itself, **?** and **F1** open this topic.

## Links

A link to another topic opens it inside the Help page. A link to a web address opens in your browser.

## Language

Use the **EN** / **RU** switch at the top of the Help page to read the help in English or Russian.
The first time, the language follows your Windows display language: Russian Windows shows Russian, any other shows English.
Your choice is remembered in `settings.json`.

The application itself is in English only. The Russian help names buttons and pages exactly as they appear
in the application, in bold.
