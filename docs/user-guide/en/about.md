# About

The **About** page shows:

- the application name and version;
- the license (MIT License);
- the project address on GitHub. Click it to open it in your browser;
- the **data folder**, where LeftoverScout keeps `settings.json` and the logs.

Click **Open data folder** to open that folder in Explorer. This is useful when you want to look at the
log files or report a problem.

See [Getting started](getting-started.md) for what is stored in the data folder.
