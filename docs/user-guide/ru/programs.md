# Programs

Страница **Programs** показывает, что установлено на этом компьютере. Каждое сканирование [Scan](scan.md) собирает
этот список автоматически вместе с размерами папок. В следующих версиях он будет использоваться, чтобы понять,
принадлежит ли папка в вашем профиле установленной программе.

**Ничего не изменяется.** Реестр только читается, файлы ярлыков никогда не открываются, и отсюда нельзя ни запустить,
ни удалить программу.

## До первого сканирования

Если ни одно сканирование ещё не завершилось, на странице показывается короткое сообщение и кнопка **Go to Scan**.
Если вы отмените следующее сканирование, на странице остаётся список предыдущего завершённого сканирования.
Новое завершённое сканирование заменяет его.

## Заголовок

Над таблицей видно, когда собран список и сколько в нём записей, например
«Collected 3/4/2025 12:30 PM · 312 programs». Если какой-то источник не удалось прочитать, об этом сообщает одна
короткая строка под заголовком, например «Store apps could not be read.». Остальные источники при этом показываются.

## Откуда берутся записи

LeftoverScout смотрит в четырёх местах. Одна и та же программа часто есть в нескольких из них, поэтому имя может
встречаться несколько раз. Это нормально.

| Источник | Что это |
|---|---|
| **Registry** | Список, который лежит за страницей Параметры Windows → Приложения → Установленные приложения (разделы реестра `Uninstall` компьютера и вашего пользователя, 64- и 32-разрядные). Обновления и исправления не включаются. |
| **Store** | Приложения из Microsoft Store и другие упакованные (MSIX) приложения, установленные для вашего пользователя. |
| **Program folder** | Папки прямо внутри `Program Files`, `Program Files (x86)` и `%LOCALAPPDATA%\Programs`. Используется только имя папки. |
| **Start menu** | Имена ярлыков и папок в вашем меню «Пуск» и в меню «Пуск» для всех пользователей. Сами файлы ярлыков никогда не открываются. |

## Поиск и фильтры

- **Search**: введите часть названия или издателя. Таблица фильтруется по мере ввода; регистр букв не важен.
- **Source**: **All**, **Registry**, **Store**, **Program folder** или **Start menu**.
- **Show system components and frameworks**: по умолчанию выключено. Скрывает компоненты Windows, системные
  приложения и пакеты-фреймворки, которые редко нужны. Включите, чтобы увидеть всё.

Под таблицей «<показано> of <всего> programs» говорит, сколько записей проходит фильтры. Пока системные
компоненты и фреймворки скрыты, в строке также указано, сколько записей это скрывает, например
«476 of 871 programs · 395 hidden (system components and frameworks)». Если ничего не скрыто, показывается
короткая форма. Если ни одна запись не проходит фильтры, страница сообщает об этом.

## Таблица

| Столбец | Значение |
|---|---|
| **Name** | Название программы, приложения, папки или ярлыка. |
| **Publisher** | Кто выпустил, если известно. |
| **Version** | Версия, если известна. |
| **Source** | Где найдена запись, см. выше. |
| **Install location** | Папка установки, если известна. |
| **Installed** | Дата установки, если программа её записала. |

Нажмите на заголовок столбца для сортировки; повторное нажатие меняет порядок. Сначала таблица отсортирована по
**Name**, и стрелка на заголовке это показывает. Пустая ячейка значит, что этот источник не даёт такой информации.

## Кнопки и сочетания клавиш

Кнопки находятся над таблицей и в контекстном меню строки (правая кнопка мыши). Пока строка не выбрана, они неактивны.

- **Open install location**: открывает папку установки в Проводнике. Доступно только если у записи есть место
  установки и эта папка существует.
- **Copy name**: копирует название в буфер обмена. Сочетание: **Ctrl+C**.
- **F1** или кнопка **?**: открывает этот раздел справки.

## Советы

- Сравните несколько записей с Параметры Windows → Приложения → Установленные приложения, чтобы убедиться, что список правдоподобен.
- Записи из **Program folder** и **Start menu** — только подсказки. Папка может остаться после удаления программы.
- Чтобы найти остатки удалённой программы, поищите её название здесь: если его нет ни в одном источнике,
  программа, скорее всего, удалена.

Дальше: страница [Findings](findings.md) перечисляет, что можно удалить, [Results](results.md) показывает, куда уходит место.
