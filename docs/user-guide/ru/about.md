# About

Страница **About** показывает:

- название и версию программы;
- лицензию (MIT License);
- адрес проекта на GitHub. Нажмите на него, чтобы открыть в браузере;
- **папку данных**, где LeftoverScout хранит `settings.json` и журналы.

Нажмите **Open data folder**, чтобы открыть эту папку в Проводнике. Это полезно, если нужно посмотреть
файлы журнала или сообщить о проблеме.

О том, что хранится в папке данных, см. [Начало работы](getting-started.md).
