# Cleanup

Страница **Cleanup** запланирована. Она переместит выбранные вами элементы в Корзину после вашего подтверждения,
чтобы их можно было восстановить. Пока она недоступна: на странице только короткая заметка, а LeftoverScout
сейчас ничего не удаляет.

Элементы для очистки будут выбираться на странице [Findings](findings.md); **Cleanup** затем запросит подтверждение и покажет ход выполнения.

См. также [Results](results.md) и [History](history.md).
