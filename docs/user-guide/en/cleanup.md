# Cleanup

The **Cleanup** page is planned. It will move the items you select to the Recycle Bin after you confirm,
so you can restore them. It is not available yet: the page only shows a short note, and LeftoverScout
does not delete anything today.

The items to clean up will be selected on the [Findings](findings.md) page; **Cleanup** will then ask for confirmation and show progress.

See also [Results](results.md) and [History](history.md).
