# Как пользоваться справкой

## Как открыть справку

- Нажмите **Help** в навигации, чтобы прочитать все разделы. Список разделов слева, текст справа.
- Нажмите кнопку **?** в правом верхнем углу любой страницы или клавишу **F1**, чтобы открыть справку
  по текущей странице. На самой странице **Help** кнопка **?** и **F1** открывают этот раздел.

## Ссылки

Ссылка на другой раздел открывает его внутри страницы Help. Ссылка на веб-адрес открывается в браузере.

## Язык

Переключатель **EN** / **RU** вверху страницы Help меняет язык справки: английский или русский.
В первый раз язык определяется языком интерфейса Windows: на русской Windows справка русская, на любой другой английская.
Ваш выбор запоминается в `settings.json`.

Сама программа только на английском. В русской справке кнопки и страницы называются так же, как в программе,
и выделены жирным.
