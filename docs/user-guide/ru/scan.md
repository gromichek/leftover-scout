# Scan

Откройте страницу **Scan** и нажмите **Start scan**. LeftoverScout обходит ваш профиль пользователя
(`C:\Users\<вы>`) и измеряет, что занимает место.

**Ничего не изменяется.** Сканирование только читает списки папок: оно не открывает ваши файлы, ничего
не удаляет, не перемещает и не переименовывает и не меняет даты. Пока идёт сканирование, окно остаётся доступным.

## Кнопки

- **Start scan**: запускает сканирование. Пока оно идёт, кнопка неактивна.
- **Cancel**: останавливает сканирование, обычно примерно за секунду. После отмены показывается
  «Scan cancelled.», итогов нет. Если сканирование не идёт, кнопка неактивна.

## Во время сканирования

Вы видите папку, которая читается сейчас, сколько найдено папок и файлов, размер на данный момент и прошедшее время.
В строке состояния внизу сначала «Scanning…», затем «Scan completed in 42 s» или «Scan cancelled».

## Итоги

| Строка | Значение |
|---|---|
| Local size | Размер всех файлов, хранящихся на этом компьютере (логический размер файла, как в Проводнике в поле «Размер»). Файлы с жёсткими ссылками считаются по разу на каждую ссылку. |
| Cloud-only size | Размер файлов, которые есть только в облаке (например, файлы OneDrive «только в сети»). Здесь они не занимают места и **не входят** в Local size. Сканирование их никогда не скачивает. |
| Personal folders | Локальный размер папок Documents, Desktop, Pictures, Videos, Music, Downloads и OneDrive. Они измеряются, но помечаются как личные, потому что в следующих версиях их никогда не предложат к удалению. |
| Folders / Files | Сколько найдено папок и файлов. |
| Skipped links | Соединения (junction) и символические ссылки. LeftoverScout не переходит по ним, поэтому ничего не считается дважды или вне вашего профиля. Windows создаёт в каждом профиле несколько старых ссылок (например, `Application Data`), поэтому обычно значение не равно нулю. |
| Cloud folders not scanned | Папки OneDrive, недоступные на этом компьютере. Их чтение заставило бы OneDrive скачать их, поэтому LeftoverScout их не трогает. |
| Inaccessible locations | Папки, которые не удалось прочитать (доступ запрещён или другая ошибка). Сканирование продолжается без них, поэтому итоги могут быть немного меньше реальных. |
| Duration | Сколько длилось сканирование. |

Под итогами **Largest top-level folders** показывает десять самых больших папок прямо в вашем профиле
(по локальному размеру). Среди них часто бывает `AppData`.

## Советы

- Диалог *Свойства* в Проводнике считает ещё и облачные файлы, переходит по некоторым ссылкам и не может
  прочитать некоторые папки. Разница нормальна: сканирование показывает, куда уходит место, а не совпадает с Проводником до байта.
- Сканирование большого профиля может занять время. Можно продолжать пользоваться окном или нажать **Cancel**.
- Файлы от 100 МБ запоминаются как «большие файлы» и показываются на странице **Results**.
- Последний завершённый результат хранится в памяти, пока программа работает. Новое сканирование заменяет его.

Дальше: страница [Results](results.md) показывает, куда уходит место.
